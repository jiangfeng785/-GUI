# 图形化贪吃蛇游戏

> C++ 课程设计项目，基于 Visual Studio + EasyX 图形库实现。
> 采用 MVC（Model-View-Controller）架构，支持道具、技能、BFS 寻路辅助、动态关卡、音效与多套蛇皮肤。

## 项目简介

地图采用 20x20 二维网格，底层使用 `char gameMap[25][25]` 防止数组越界。玩家操控蛇在地图移动，吃食物获得分数，躲避炸弹、墙体与障碍物，挑战关卡与最高分记录。

**主要功能：**

- 蛇移动控制，暂停/继续，游戏重开，技能释放
- BFS 寻路路径辅助提示
- 关卡升级与动态难度调节，移动速度随关卡变化
- 多种游戏元素：红苹果、金苹果、炸弹、传送门、可撞击障碍物
- 蛇身多套动态皮肤，根据分数自动切换外观
- wav 音效播放（独立音频线程，消除卡顿）
- 本地文件读写保存最高分 `highscore.txt`
- 障碍物撞击计数，撞击 3 次后碎裂消失

**游戏元素标记：**

| 标记 | 对象 |
| --- | --- |
| H | 蛇头 |
| B | 蛇身 |
| F / / | 普通食物 |
| * | 炸弹 |
| # | 墙体 |
| O | 障碍物 |
| @ | 传送门 |

## 游戏规则

1. **移动**：`W A S D` / 方向键控制蛇移动，禁止直接反向移动，反向判定死亡。
2. **得分**：红苹果 +10 分；金苹果 +50 分；触碰炸弹 -20 分。吃到食物蛇身增长一节。
3. **游戏结束条件**：蛇头撞墙、撞障碍物、撞到自身、直接反向移动、分数小于 0。
4. **障碍物**：被撞击 3 次后碎裂消失。

## 界面设计

- **游戏主区（左侧）**：600x600 像素（20x20 网格，每个格子 30px）
  - 蛇皮肤切换规则：
    - 0-100 分：基础绿色蛇
    - \>100 分：金色神龙
    - \>500 分：赛博机甲蛇
  - 绘制食物、炸弹、传送门、障碍物
- **信息控制面板（右侧，220px）**
  - 游戏标题、当前分数、历史最高分、当前关卡
  - 游戏状态提示（暂停、游戏结束）
  - 按键操作说明
- **启动教程页**：3 页教程，按任意按键翻页进入游戏

### 关卡升级逻辑

当 `score / (gameLevel * 200) == 1`，自动升级关卡；重置地图，刷新全部道具，关卡 +1，移动间隔缩短，难度提升。

## 系统架构（MVC）

- **Model（模型，业务逻辑层）**：地图数据、蛇移动、碰撞检测、BFS 寻路、技能、关卡逻辑。
- **View（视图，渲染层）**：EasyX 图形绘制，双缓冲绘图防止闪烁；绘制地图、蛇、道具、UI 面板、教程页面。
- **Controller（控制器，输入层）**：捕获键盘输入，处理方向、暂停、技能、游戏状态切换。
- **Audio 音频模块**：独立后台线程 + 任务队列，异步播放 wav 音效，避免游戏卡顿。

## 核心算法说明

### 1. 动态关卡算法

> `score / (gameLevel * 200) == 1` 触发升级；重置地图、刷新全部道具，关卡自增。

### 2. 炸弹动态重定位

维护步数计数器，蛇每移动一步计数器 +1；计数器对 10 取模等于 0 时，炸弹随机迁移到地图安全空白位置。

### 3. 独立音频线程队列

音频模块维护播放任务队列与条件变量；游戏逻辑推送播放任务，后台线程顺序消费播放 wav 音频；线程 detach 分离，程序退出可以播放完剩余音效。

### 4. BFS 最短路径搜索

以蛇头为起点向食物做广度优先搜索；墙体、障碍物、炸弹、蛇身、传送门视作不可通行；找到路径后在暂停模式高亮显示路径光点。

## 编译运行

### 环境依赖

- Windows 操作系统
- Visual Studio 2022
- EasyX 图形库

### 编译步骤

1. Clone 本仓库
2. 使用 VS 打开 `snake.sln`
3. 生成 -> 重新生成解决方案
4. F5 调试运行

> ⚠️ 如果直接双击 exe 运行：**必须把 `res/` 资源文件夹复制到 exe 同级目录**，否则图片、wav 音效、最高分文件无法加载。

### 资源目录说明

```
snake/res/
├── *.png            // 游戏图片素材
├── *.wav            // 游戏音效
└── highscore.txt    // 最高分本地存储文件
```
